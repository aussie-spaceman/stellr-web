## Rollback caveat

`event_awards` is not fully backward-compatible: the pre-#201 issuer (`app/api/admin/events/[slug]/credentials/route.ts:124` at `bc28af1`) inserts `source: 'event'` credentials with no `award_type`, which the new `credentials_event_award_type` CHECK rejects. Between the migration and the deploy, and after any rollback to `bc28af1`, issuing event credentials fails (nothing else does). Production has 0 event credentials, so exposure is small. After a rollback: `ALTER TABLE public.credentials DROP CONSTRAINT credentials_event_award_type;`.
