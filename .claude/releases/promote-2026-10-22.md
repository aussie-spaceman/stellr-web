## What ships
- **#453 Fix certificate "Save position" returning Database error** (`4a938b27`).
  - Save position on the competition Settings tab failed for every award with `23502` (NOT NULL on `artwork_path`). It sent only the placement, and the route upserted it, but Postgres checks NOT NULL on the row an upsert would insert before it resolves the conflict.
  - Every production template still had the default placement, so no position save had ever persisted.
  - When the template exists, the route now updates only the fields sent; the first artwork upload still upserts.
  - Found on production on 22 Oct, right after the first Norm Chaffee artwork upload, which itself saved fine.
- **#451 Cut Vercel Active CPU** (`94e4b756`). Price caches 60 s → 1 h, so the homepage, `/competitions`, `/membership` and event pages stop re-rendering every minute. `prefetch={false}` on links to dynamic pages. Studio slug-guard asks the API only when the slug really changed. Static manifests (the app host's served through a host-scoped `beforeFiles` rewrite). The proxy matcher skips `/api/img`. The Stripe webhook revalidates both price caches on `price.created/updated/deleted` and `product.updated`.
- **#452 Fix apollo-reconcile: finish inside 60 s and resume** (`4b11faac`). Stops starting prospects at 40 s and stores `nextOffset` in `cron_runs.result`; the next run resumes from it. No migration.
- **#450:** close-out docs for the norm-chaffee-award session (handover + tracker).
- **#449:** the 2026-10-19 promotion record and `main` → `dev` sync.
