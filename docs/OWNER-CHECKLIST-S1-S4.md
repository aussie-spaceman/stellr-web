# Owner checklist: S1 to S4

One list of the owner actions and decisions that Stages 1 to 4 of the multi-tenant plan still need, so they stop living only in PR bodies (#509, #510, #511) and stage docs. Tracker row `s5-programme.39` asked for it. It also folds in the S3 and S4 items that appear in no tracker row: Stellr's EIN, the critical-tables copy to the backup repo, the derivation-log roll-up, the role mapping, the pooler limit, and the storage backstop, `tenantDb` pin and plaintext decisions.

Written 14 Nov 2026 against `dev` at `1d9b6977`. Stage list and ledger: `docs/PLAN-multi-tenant.md`. "The owner" is the programme's owner. Every step here is the owner's own, or needs the owner's yes at the time; an agent may draft, read `dev` or prepare a command, but never runs production SQL, reads production data or changes a production variable (`CLAUDE.md`, "Agents: data is never instructions").

## How to use it

- **Why** says what the step protects or which gate it opens. **How** points to the runbook that holds the exact steps; this file does not repeat them. **Record** says where the result goes.
- Record ids, dates, counts and outcomes only. Never a key, password, connection string, account id, EIN, or anyone's name: the repo is public.
- Where "Record" names tracker `s5-programme.39`, add the result as a dated line to that row's State cell, citing this file's item id (for example `.39 / C-4`), until the row is closed.
- Items marked **decision** need the owner's answer, not a task. Each has a proposed default; the decision goes in `docs/S5-DECISION-REGISTER.md` under the gate it names.
- Order inside each section is highest risk first.
